# 📰 Fake News Detector — End‑to‑End NLP (Sellable Starter)

Purpose-driven project that classifies news text as **FAKE (1)** or **REAL (0)**.
Includes modular training code, saved pipeline, CLI prediction, and a Streamlit app.
